# Define matrix ownership and versioning

## Question

What can administrators change, and what happens when a matrix changes during or after an assessment?

## Answer

Administrators create, edit, preview, and publish job-role matrices containing domains, competencies, required levels, importance, rubrics, baseline questions, and course tags. An active assessment keeps the published matrix version it started with. On a later visit, an official sees that a newer matrix exists and may start a reassessment.
